# Einzelne Photonen im Mach-Zehnder-Interferometer

Lernumgebung des foeXlab (Leibniz Universität Hannover) für den Kurs „Mach-Zehnder-Interferometer“: drei Aufbauten, Quantenradierer und delayed choice.

`index.html` ist eine einzelne, vollständige Datei. Sie wird aus den bearbeitbaren Quelltexten (Ordner „MZI einzelne Photonen“, `Aktualisieren.command`) erzeugt. Diese öffentliche Fassung nutzt Helvetica/Arial statt der Hausschrift Rotis.

## Die Blackbox öffnen

`blackbox-oeffnen.html`: Lernumgebung zur Vorbereitung auf das Realexperiment zur Koinzidenzmethode im foeXlab (Detektoren, Dunkelzählrate, Koinzidenzen, Photonenpaare, angekündigte Photonen; Kapitel 7 im foeXlab). Gleicher Rahmen wie die MZI-Lernumgebungen. Sie wird aus dem Quellordner „Blackbox oeffnen Lernumgebung“ erzeugt (`Blackbox_oeffnen_Lernumgebung_Weitergabe.html`), ohne Rotis.

## MZI: Aufbau und Justage

`aufbau/index.html`: Lernumgebung zum klassischen Teil des Kurses (Wiederholung, Bauteile, Schema per Drag and Drop, Fehlerquellen, Materialliste, Aufbau mit Video oder Anleitung, Vergleich der Interferenzmuster). Sie wird aus dem Quellordner „MZI Aufbau“ erzeugt (`MZI_Aufbau_Lernumgebung.html`), ebenfalls ohne Rotis. Das Aufbauvideo ist eingebettet, daher ist die Datei etwa 36 MB groß.
